# Adopted UI Skill Research

- Anthropic `frontend-design`: adopt subject-grounded visual direction, a deliberate memorable thesis, intentional typography/composition, and critique against templated defaults. Omit its code-generation instructions because UI_DESIGN does not implement source.
- NextLevelBuilder `ui-ux-pro-max`: adopt priority ordering that treats accessibility and interaction safety as critical, plus explicit checks for contrast, focus, target size, feedback, responsive behavior, performance, and motion. Omit its web-stack database and fixed style catalog.
- Vercel `web-design-guidelines`: adopt rule-based pre-delivery review for accessibility, focus, controls, animation, content states, and performance. Translate browser-specific rules into engine-neutral game UI outcomes.
- Huey Asegun's `ui-visual-composition`: adopt the structure-first and grayscale-first workflow, explicit priority ranking, semantic grouping, constrained tokens, one light/elevation model, resilient real-content checks, and a visual critique pass. Omit web semantics and generic SaaS defaults.
- `Claude-Code-Game-Studios` UI pipeline: adopt a deliberate separation between UX structure and visual treatment, explicit asset briefs, an interface-pattern system, engine-aware handoff, screen-size review, and a HUD visual budget. Keep these as one UI_DESIGN responsibility because DeviLudo intentionally has a single UI design stage.
- `GameUIAgent`: adopt a structured intermediate visual specification and a self-reflection pass rather than single-shot prose. Its reported game-domain failure mode of visual emptiness motivates explicit composition and density checks. Omit its Figma-specific rendering and rarity-template pipeline.
- Apple game HIG: adopt game-specific safe areas, adaptive aspect-ratio layouts, platform-appropriate readable text and targets, controller-label conventions, contextual touch controls, and familiar menu navigation.
- Microsoft Xbox Accessibility Guidelines: adopt game-specific tests for HUD/text contrast, alternate cue channels, UI navigation, focus, context, error recovery, motion, and configurability.
- Godot GUI skinning guidance: treat the engine theme as a cascading design system and explicitly replace stock Control-node appearance instead of composing a final UI from defaults.
